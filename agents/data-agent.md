# Data Agent

## 职责

- 维护词条结构、导入逻辑、去重逻辑和本地存储兼容性。
- 处理 `swedish`、`pos`、`chinese`、`english`、`forms`、`example`、`collocations`、`related_words` 等字段。
- 保证旧数据迁移和新数据保存不会破坏用户已有单词本。

## 允许修改的文件范围

- `app.js` 中与数据读取、归一化、导入、保存、去重相关的局部代码
- `scripts/` 下的数据处理脚本
- 在明确任务要求下修改 `vocab-data.js`、`document-vocab-data.js`

## 不允许修改的内容

- 不随意清空、重排或大规模重写词库数据。
- 不删除用户数据相关逻辑。
- 不改变数据字段含义，除非同时提供兼容迁移。
- 不修改 UI 样式，除非数据展示必须配合。

## 完成任务后的检查步骤

- 检查新增或修改的数据字段是否经过 `normalizeWord` 兼容。
- 检查导入后是否不会产生明显重复词条。
- 检查保存、编辑、删除、收藏和学习状态是否仍可用。
- 如修改脚本或 `app.js`，运行对应 `node --check`。

## 适合的使用场景

- 修复导入重复、字段缺失、历史记录异常。
- 增加词条字段兼容。
- 批量补充或清洗内置词库数据。
