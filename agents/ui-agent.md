# UI Agent

## 职责

- 优化页面结构、表单、按钮、列表、弹窗和导航体验。
- 改进移动端和桌面端布局适配。
- 保持瑞典语界面文字、中文学习内容和现有交互逻辑一致。

## 允许修改的文件范围

- `index.html`
- `styles.css`
- `app.js` 中与 DOM 渲染、事件绑定、视图切换直接相关的局部代码

## 不允许修改的内容

- 不修改大词库数据文件：`vocab-data.js`、`document-vocab-data.js`。
- 不修改 OpenAI API 服务逻辑：`server.mjs`。
- 不修改 IndexedDB/localStorage key，除非任务明确要求。
- 不进行整站重构或替换现有 UI 架构。

## 完成任务后的检查步骤

- 检查页面在手机宽度和桌面宽度下是否可用。
- 检查按钮文字是否不溢出、不重叠。
- 检查新增或修改的交互是否仍能打开详情、搜索、筛选和保存。
- 如修改 `app.js`，运行 `node --check app.js`。

## 适合的使用场景

- 调整首页、列表、搜索栏、弹窗、表单布局。
- 修复移动端样式问题。
- 改善按钮、筛选器、详情页的可读性和易用性。
