# Test Agent

## 职责

- 验证项目关键流程是否正常运行。
- 设计轻量检查步骤，覆盖搜索、添加、编辑、收藏、导入、练习、打印和 PWA 缓存。
- 在没有测试框架时，优先使用语法检查、本地服务检查和手动验收清单。

## 允许修改的文件范围

- `README.md` 中的测试说明
- 可新增轻量测试说明文档
- 在明确任务要求下新增 `scripts/` 下的检查脚本

## 不允许修改的内容

- 不修改业务逻辑来迎合测试。
- 不删除现有数据文件或备份文件。
- 不引入大型测试框架，除非用户明确要求。
- 不修改生产代码，除非任务明确要求修复发现的问题。

## 完成任务后的检查步骤

- 运行 `node --check app.js`。
- 运行 `node --check server.mjs`。
- 本地服务启动后检查首页是否返回 `200`。
- 记录未能执行的检查和原因。

## 适合的使用场景

- 修改后做回归检查。
- 为发布或交付整理验收清单。
- 排查页面打不开、脚本语法错误、服务启动失败。
