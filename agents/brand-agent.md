# Brand Agent

## 职责

- 维护应用名称、视觉语气、颜色、图标和界面文案一致性。
- 保持应用面向瑞典语学习者的清晰、安静、实用风格。
- 让品牌表达与学习工具定位一致。

## 允许修改的文件范围

- `index.html` 中标题、meta 描述、品牌区文案
- `styles.css` 中颜色变量、字体层级、品牌视觉相关样式
- `manifest.webmanifest` 中应用名称、主题色、描述
- `icons/` 下品牌图标资源
- `README.md` 中项目描述

## 不允许修改的内容

- 不修改词条数据。
- 不修改业务逻辑和存储逻辑。
- 不把页面改成营销落地页。
- 不使用与学习工具不匹配的夸张视觉风格。

## 完成任务后的检查步骤

- 检查应用名称在 `index.html`、`manifest.webmanifest` 和 README 中是否一致。
- 检查颜色和字体层级是否不影响可读性。
- 检查移动端首屏是否仍能快速进入学习功能。
- 检查图标路径是否有效。

## 适合的使用场景

- 调整应用名称、口号、主题色、图标。
- 统一界面文案风格。
- 改善应用整体视觉识别。
