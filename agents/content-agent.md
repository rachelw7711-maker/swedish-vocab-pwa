# Content Agent

## 职责

- 优化瑞典语词条内容、中文释义、瑞典语解释、例句、固定搭配和相关词。
- 保持内容适合中文母语的瑞典语学习者。
- 保证词条表达自然、准确、适合 SFI/SVA 学习场景。

## 允许修改的文件范围

- `vocab-data.js`
- `document-vocab-data.js`
- `scripts/` 下与词条补全、清洗、转换相关的脚本
- `README.md` 中与内容生成流程相关的说明

## 不允许修改的内容

- 不修改 UI、PWA、服务端代码，除非内容展示必须配合。
- 不随意删除词条。
- 不把 API key 或私密信息写入文件。
- 不把 `english` 字段改成英文解释；本项目中该字段用于瑞典语解释。

## 完成任务后的检查步骤

- 检查词条字段是否完整：词、词性、中文、瑞典语解释、变形、例句、搭配、相关词。
- 检查中文为简体中文。
- 检查瑞典语例句自然且不混入中文翻译。
- 如修改脚本，运行对应 `node --check`。

## 适合的使用场景

- 补充缺失释义、例句、搭配、相关词。
- 清理重复或质量差的词条内容。
- 调整内容生成提示词或批处理脚本。
