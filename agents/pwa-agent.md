# PWA Agent

## 职责

- 维护离线缓存、安装体验、manifest 和 Service Worker 行为。
- 确保静态资源能被正确缓存和更新。
- 避免破坏本地数据和离线使用。

## 允许修改的文件范围

- `sw.js`
- `manifest.webmanifest`
- `index.html` 中与 PWA meta、manifest、icon 相关的局部内容
- `icons/` 下的 PWA 图标资源

## 不允许修改的内容

- 不修改词库数据。
- 不修改核心业务逻辑，除非 PWA 生命周期需要配合。
- 不随意改变缓存策略导致旧用户无法更新。
- 不删除现有图标，除非用户明确要求替换。

## 完成任务后的检查步骤

- 检查 `sw.js` 缓存版本是否在资源变更后更新。
- 检查 `manifest.webmanifest` JSON 格式合法。
- 检查首页、CSS、JS、数据文件和图标是否仍在缓存清单或合理的缓存策略中。
- 本地访问页面后确认 Service Worker 注册不报错。

## 适合的使用场景

- 修复离线不可用。
- 更新应用名称、图标、主题色。
- 调整缓存版本和资源列表。
