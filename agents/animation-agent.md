# Animation Agent

## 职责

- 添加或优化轻量动效，提升交互反馈。
- 处理按钮、弹窗、列表项、加载状态和视图切换动画。
- 保持动画克制、快速、不会影响学习效率。

## 允许修改的文件范围

- `styles.css`
- `app.js` 中与动画状态 class、加载状态、交互反馈相关的局部代码

## 不允许修改的内容

- 不引入大型动画库，除非用户明确要求。
- 不改变核心数据逻辑。
- 不添加影响性能的大量动画。
- 不让动画阻塞搜索、保存、导入等关键操作。

## 完成任务后的检查步骤

- 检查动画是否在移动端不卡顿。
- 检查 `prefers-reduced-motion` 用户是否不会被强制播放复杂动画。
- 检查文字、按钮、列表项在动画期间不重叠。
- 如修改 `app.js`，运行 `node --check app.js`。

## 适合的使用场景

- 给弹窗、列表加载、按钮点击增加反馈。
- 优化页面切换手感。
- 修复动效导致的布局抖动。
